# Third-party runtime components

The Windows package redistributes the MSYS2 CLANG64 GTK 2 runtime closure.
This includes GTK, GLib, GIO, GObject, GModule, ATK, Cairo, Pango,
GdkPixbuf, Fontconfig, FreeType, HarfBuzz, image codecs, text-layout support,
compression libraries, the LLVM C++ runtime, and the Adwaita and hicolor icon
themes.

The corresponding upstream license files are installed below
`share/doc/pure-gtk/licenses`, grouped by MSYS2 package name. These files are
part of the runtime distribution and must remain with redistributed bundles.
